## 1. Volumetric Analysis & Titration Essentials
* **Titrant:** Solution of known concentration delivered from the **Burette**.
* **Titrand (Analyte):** Solution being measured, pipetted into the **Conical Flask**.
* **Equivalence Point:** Theoretical point where stoichiometric amounts react.
* **Endpoint:** Physical point where indicator exhibits sharp color transition.

---

## 2. Key Indicator Choices
* **Strong Acid vs. Strong Base (e.g. $\text{HCl} + \text{NaOH}$):**
  * Methyl Orange (pH 3.1 - 4.4, Red to Yellow) OR Phenolphthalein (pH 8.3 - 10.0, Colorless to Pink).
* **Strong Acid vs. Weak Base (e.g. $\text{HCl} + \text{Na}_2\text{CO}_3$):**
  * Methyl Orange (Equivalence point is acidic, $\text{pH} \approx 3.8$).
* **Weak Acid vs. Strong Base (e.g. $\text{CH}_3\text{COOH} + \text{NaOH}$):**
  * Phenolphthalein (Equivalence point is alkaline, $\text{pH} \approx 8.7$).

## 3. Essential Volumetric Formulas
$$C_A V_A / n_A = C_B V_B / n_B$$
$$\text{Molarity } (M) = \frac{\text{Mass in grams}}{\text{Molar Mass } (g/mol) \times \text{Volume in } dm^3}$$
$$\text{Mass Concentration } (g/dm^3) = \text{Molarity } (mol/dm^3) \times \text{Molar Mass } (g/mol)$$
